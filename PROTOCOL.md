## Gate design

Admissible source design = documentation for one corpus, or common-protocol combination explicitly documented by these records. Sources serving different components do not establish cross-corpus historical comparability by count union or name matching.

H1 Historical evidence state: documentation supports recovering text and action-driving metadata actually available at specified past cutoffs, not merely records published before them. Historical citations, concepts, abstracts, affiliations and corrections need vintage provenance if used. Any feature using citation counts, concepts/topics, author/institution disambiguation or reference lists must have documented as-of state or be excluded. OpenAlex topics/concepts are model-assigned at ingestion; this is a required gate fact to verify in admitted documentation, not proof of as-of state. Post-cutoff retractions/corrections must be excluded or vintage-tracked. Abstract provenance is required; no assertion about inverted-index storage. Date semantics must distinguish publication_date, e-publication, indexing/entry and first-seen, and document which supports available-at-cutoff. Current created_date/updated_date and current citation counts cannot silently stand in for historical state.
H2 Input versus target separation: archived input evidence must be separable from later discoveries/student-project outcomes. Labels require independent dated provenance, full denominator including failed/unrealized opportunities and exclusion of overlap. Year labels or winning-only project filters do not establish testability or unbiased opportunity labels. ISEF abstract search covers finalist projects only, a survivorship-biased set, not the denominator of all attempted opportunities. Student-project discovery labels are not discovery events. Documentation must establish whether a target can be excluded from as-of inputs; otherwise UNKNOWN. Unknown label construction stays UNKNOWN.

Documentation must support those fields, not retrospectively infer capabilities from later review language. Current corpus metadata cannot prove field maturity or biological testability.

Independent means no shared paper, no shared first/last author group and no shared method, as documented by records. Domains must be fixed before any label is read; none are selected in F0. The draft does not define the third capability, and no F0 verdict is about any specific capability. Actual target counts unknown without registered label audit.
